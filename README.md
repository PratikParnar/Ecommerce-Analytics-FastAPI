# E-Commerce Analytics API

## Project Overview

This project analyzes the Brazilian E-Commerce Dataset using Python, Pandas, and FastAPI.

The project provides analytics APIs for revenue, customers, products, orders, and payment insights.

## Tech Stack

- Python
- Pandas
- NumPy
- FastAPI
- Jupyter Notebook
- GitHub

## Features

- Total Orders Analysis
- Revenue Analysis
- Customer Insights
- State-wise Revenue Analysis
- Monthly Revenue Trends
- Top Products Analysis
- Payment Method Analysis
- REST APIs using FastAPI

## Available APIs

- /total-orders
- /order-status
- /monthly-orders
- /total-revenue
- /average-order-value
- /payment-methods
- /top-states
- /total-customers
- /monthly-revenue
- /top-products
- /state-revenue
- /customer-insights
- /dashboard-summary

## Dataset

Brazilian E-Commerce Public Dataset (Olist)
